The PDF viewer for reviewing typeset pages.

Hover any text to see its font and size. Measure any region in points, picas, millimetres or inches. Mark up what needs fixing, and keep reading while LaTeX or Typst rebuilds the file — NeoView reloads it in place.

Features

One window for the whole review pass.

Reading, measuring, inspecting, marking up and rebuilding usually means four programs. NeoView keeps them in one, organised around the job you are doing.

Inspect and measure

See the font under the cursor

Switch to the Select tool and hover any text. NeoView outlines the span and the inspector shows its font name, size in points and style — the quickest way to catch a substituted font, a heading in the wrong weight or body text at 10.95 pt where the design says 10.

  • Works on every span: body text, headings, captions, code
  • Bold and italic detected from the font name
  • Document panel lists title, author, producer, PDF version, dates, encryption and file size

Measure in the units of your spec

Drag a rectangle with the Measure tool. Width, height, X and Y appear on the page in points and in the inspector in points, picas, millimetres or inches. Fine-tune it from the keyboard and copy the numbers.

  • Resize with handles, move by dragging
  • Arrow moves 1 pt, Shift+Arrow 10 pt; add Ctrl to resize
  • Ctrl+C copies the size in pt, pc and mm
  • Ctrl+S saves the area as a PNG at 150, 300 or 600 DPI

Rulers and a layout grid

Turn on rulers along the edges of the view, and lay a grid over every page to check margins, columns and baseline alignment. Set the line spacing, offsets, subdivisions, corner marks and colour.

  • Rulers in points; ticks adapt to the zoom
  • Grid settings are remembered

Review and annotate

Mark it up without touching the PDF

Ten annotation types with colour, opacity and stroke width. Every mark is listed in the sidebar, filterable by type, and saved next to the PDF — so the next build never loses it. When you are done, export a copy with the marks embedded and send it back.

  • Highlight, underline, strikethrough, sticky note, text box
  • Rectangle, ellipse, line, arrow, freehand
  • Edit properties, jump to, or delete from the list
  • Annotations already in the PDF are shown and listed

Read and navigate

Find every match, with context

Results appear while you type. The results panel lists each match with its page and the line it sits on; click one to go there. Match case when you need it.

  • Ctrl+F to search, F3 / Shift+F3 for next and previous
  • Long documents are searched in batches, so the window stays responsive

Jump anywhere, then come back

Filter the outline and jump to a section, follow a cross-reference, or click a thumbnail. Back and forward return you to the exact spot and zoom you left. Add your own bookmarks with Ctrl+D.

  • Sidebar with thumbnails, outline, bookmarks and annotations
  • Internal links followed; web links open in your browser
  • Several documents in tabs

Zoom around the point you are looking at

Pinch on a touchpad or use Ctrl+wheel: the word under the cursor stays where it is. Fit width, fit page, actual size and presets from 50 to 400 % are one key or click away.

Read the way you like

Single page, continuous, two pages side by side, or two pages with a cover. Night and sepia reading modes recolour the pages, not your annotations. Present full screen with F5 or print with page ranges and copies.

  • Layout and reading mode are remembered per document
  • Presentation: arrows, Space, Home/End, B to blank the screen
  • Rotate, full screen, password-protected PDFs

Built for LaTeX and Typst

Rebuild, and keep reading

Run latexmk -pvc, typst watch or any build that rewrites the PDF. NeoView notices the new file and reloads it on the same page, at the same zoom and scroll position. The old pages stay on screen until the new ones are drawn, so there is no blank flash, and a half-written file is waited out.

  • Annotations and bookmarks survive the rebuild
  • Page, zoom, layout and reading mode remembered per file
  • The last document reopens where you left it
  • Switch auto-reload off in the inspector; Ctrl+Shift+R reloads by hand

How these were measured

NeoView’s own benchmark (scripts/bench_render.py in the repository) drives the real window on four generated PDFs: 100 pages of text and vector shapes, the same with a large image on every tenth page, and two 650-page books (dense text with 20 internal links per page; the same with a distinct image on every page). Memory figures are the median of 3 runs that read every page at fit width, waiting for each to be sharp; the 0.4 runs were stopped by the harness’s 3 GB safety limit. Open and zoom figures are medians of 5 runs per document. One machine: Intel Core Ultra 5 225U, Linux 6.17, Python 3.12.3, PyMuPDF 1.28.2, PySide6 6.12.0, Qt offscreen platform. Synthetic documents on one machine — your numbers will differ. Full table in the feature inventory.

Same on every OS

Looks the same on Linux and Windows.

NeoView bundles its interface font (Inter) and icon set (Lucide), so the window looks the same whatever your desktop provides. Pick light, dark, or follow the system — the switch happens instantly, no restart.

  • Tested in CI on Ubuntu (Python 3.10–3.12) and Windows
  • No account, no network calls of its own

Install

Get NeoView.

Free for any use. Pick the way that suits your machine.

Windows

Download the standalone executable from the latest release and run it. Nothing to install.

Download neoview.exe

Or with Python:

py -m pip install neoview
neoview

Linux

Install from PyPI (Python 3.10 or newer), then open a PDF from the terminal or the welcome screen.

pip install neoview
neoview /path/to/document.pdf

Also runs as python -m neoview.

From source

Clone the repository; run.sh creates a virtual environment and starts the app.

git clone https://github.com/Srikanth-Mohankumar/neoview
cd neoview
./run.sh

Developers: python3 -m pip install -e .[dev].

FAQ

Questions.

Is NeoView really free?

Yes. It is open source under the MIT licence: free to use at work or at home, no account, no trial, no ads. NeoView makes no network connections of its own; web links inside a PDF open in your browser when you click them.

Does NeoView change my PDF?

No. Annotations and bookmarks are saved in a small sidecar file next to the PDF (document.pdf.neoview.json), which is why they survive a rebuild. Export PDF with Annotations writes a separate copy with the marks embedded as standard PDF annotations.

How does auto-reload work with latexmk or Typst?

NeoView watches the open file. When your build tool rewrites it, NeoView reloads it on the same page, at the same zoom and scroll position, and keeps showing the old pages until the new ones are drawn. A file that is empty or still being written is waited out. Auto-reload can be switched off in the inspector; Ctrl+Shift+R reloads by hand.

Which measurement units are supported?

Points, picas, millimetres and inches, chosen in the inspector or under Tools › Measurement Units. The badge on the page shows points; Ctrl+C copies the width and height in points, picas and millimetres together.

How does font inspection work?

Choose the Select tool (1) and move the pointer over text. The text span under the pointer is outlined and the inspector’s Text section shows its font name as embedded in the PDF, its size in points, and whether it is bold or italic (read from the font name).

Can it handle very long documents?

Yes. Pages render in small steps between other work and only nearby pages keep their full-resolution images, so memory stays bounded. In our benchmark a 650-page book was read end to end at 427–718 MB peak; see Performance for the conditions.

Does it open password-protected PDFs?

Yes. NeoView asks for the password (three attempts) and keeps it in memory only, so reload, printing and presentation work without asking again. It is never written to disk.

Does it run on macOS?

macOS is not a supported platform: there is no build for it and it is not tested. NeoView is developed and tested on Linux and Windows.

I found a bug or want a feature.

Please open an issue on GitHub. Pull requests are welcome.

About

Why NeoView exists.

Checking a typeset document is a loop: change the source, rebuild, find your place, look closely, measure, mark what is wrong, and do it again. Most PDF readers are built for reading, so every turn of that loop meant reaching for another tool — a ruler here, a font checker there, a separate program for markup.

NeoView started as a small crop-and-measure tool for exactly that job and grew into a full viewer around it. Version 0.5 is a ground-up redesign of the window and the rendering engine, so the precise tools sit inside a viewer that is pleasant to read in all day and stays fast on book-length documents.

It is written in Python with Qt for Python (PySide6) and PyMuPDF, and is developed in the open by Srikanth Mohankumar.
