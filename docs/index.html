Free and open source · Linux and Windows

The PDF viewer for checking typeset pages.

NeoView is for people who review PDFs and LaTeX output: measure any region in points, picas and millimetres, inspect the font under the cursor, mark up what needs fixing, and watch the PDF reload every time it is rebuilt.

pip install neoview

Features

Everything a review pass needs, in one window.

Grouped by the job you are doing.

Measure and inspect

  • Drag a rectangle and read W, H, X and Y live in points, picas and millimetres.
  • Nudge or resize from the keyboard: arrows move 1 pt, Shift moves 10 pt, Ctrl resizes.
  • Copy measurements to the clipboard with Ctrl+C.
  • Hover any text to inspect its font name, size and style.
  • Rulers and a configurable layout grid (cell size, offset, subdivisions, corner marks).
  • Export a selection as PNG at 150, 300 or 600 DPI.

Review and annotate

  • Highlight, underline and note from a selection, or draw text boxes, rectangles, ellipses, lines, arrows and freehand marks on the page.
  • Annotation list with filtering and a properties editor.
  • Your markup is saved beside the PDF in a .neoview.json sidecar; the original file is not modified.
  • Export a PDF copy with the annotations embedded.
  • Annotations already in the PDF are shown read-only.
  • Select and copy text straight from the page.

Navigate

  • Open many PDFs in tabs; opening the same file again reuses its tab.
  • Live search panel with next/previous and highlighted matches.
  • Outline, thumbnails, page info and per-document bookmarks.
  • Fit width, fit page, actual size, Ctrl+wheel and pinch zoom, rotation and full screen.
  • Keyboard shortcuts for pages, zoom, panels and selection.

LaTeX workflow

  • Auto-reload when the file changes on disk, for LaTeX, Typst or any generated PDF.
  • Reloads keep your tabs and place; F5 forces a reload.
  • Last page and zoom are restored per file, and the last open document reopens on the next launch.
  • Launch from a build script: neoview /path/to/document.pdf.

Install

Get NeoView.

Use the Windows executable, or install the Python package on Linux or Windows (Python 3.10+; PySide6 and PyMuPDF are installed with it).

Windows

Standalone executable

No Python needed. Tagged releases include a prebuilt neoview.exe.

Download neoview.exe

Install with pip

py -m pip install neoview
neoview

Build the executable yourself

From a clone of the repository:

py -m pip install .[dev]
pyinstaller neoview.spec

Output: dist\neoview.exe

Linux

Install from PyPI

pip install neoview

Run it

neoview
neoview /path/to/document.pdf

Or as a module: python -m neoview

From source

Clone the repository, then install it:

python3 -m pip install .

Or run ./run.sh instead, which sets up a virtual environment and launches NeoView.

FAQ

Questions

Is NeoView free?

Yes. NeoView is open source under the MIT License.

Does annotating change my PDF?

No. Annotations and bookmarks are stored in a sidecar file next to the PDF (document.pdf.neoview.json). When you want them inside a PDF, Export PDF with Annotations writes a separate copy.

How does auto-reload work with LaTeX?

NeoView watches the open file. When your LaTeX, Typst or other build rewrites the PDF, the tab reloads on its own, and you can press F5 to reload at any time.

Which units can I measure in?

Points, picas and millimetres, shown together for width, height and position of the selection.

Which platforms are supported?

Linux and Windows. On Windows you can use the standalone neoview.exe; on Linux install with pip install neoview (Python 3.10+).

Where do I report a bug or ask for a feature?

Open an issue on GitHub.
